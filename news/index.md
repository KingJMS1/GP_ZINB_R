# Changelog

## ZINB.GP 1.0.0

### Initial release

- Fits Bayesian zero-inflated negative binomial models with spatial,
  temporal, or spatiotemporal Gaussian process random effects.
- Supports Gaussian process effects in the zero-inflation component,
  count component, or both.
- Provides posterior draws for fixed effects, random effects, covariance
  parameters, dispersion, latent at-risk states, and predictive counts.
- Includes simulation and Oregon landslide case-study vignettes.
- Includes input validation and tests for every supported model
  configuration.
